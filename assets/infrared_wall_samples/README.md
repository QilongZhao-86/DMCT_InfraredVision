# 红外数据墙样例来源

`infrared_data_wall.svg` 使用下列来自论文定性结果图的真实热红外样例构成左侧图像墙：

- `hmtir_01.png`–`hmtir_04.png`：图 3（红外图像超分辨率样例，HM-TIR）。
- `small_target_01.png`–`small_target_04.png`：图 6（小目标检测样例，NUDT-SIRST、IRSTD-1k 和 IRSTDID-SKY）。
- `fmb_01.png`–`fmb_04.png`：图 7（FMB 红外语义分割场景）。

右侧的深度估计、检测和分割结果分别使用 `../task_examples/depth.png`、`../task_examples/detection.png` 和 `../task_examples/segmentation.png`。PNG 是 README 展示用的静态渲染图，SVG 保留为可编辑布局源文件。
